# Réveil Speedy

Toutes les 10 minutes, GitHub ouvre la page du réveil de Speedy dans Chrome : le serveur envoie
alors les rappels (10 h, 12 h, 18 h) et les alertes de courses aux téléphones de l'équipe.

L'adresse, clé comprise, est dans le secret `REVEIL_URL` (Settings → Secrets and variables → Actions).
Lancer à la main : onglet Actions → « Réveil Speedy » → Run workflow.
